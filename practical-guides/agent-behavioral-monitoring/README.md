## Goal

[RFC-195 (PR #220)](https://github.com/cosai-oasis/ws4-secure-design-agentic-systems/pull/220) proposes behavioral monitoring as a Risk Map control: compare what an agent does with what it was approved to do, and alert when the two diverge. This guide will show how to put that control in place.

## Questions this guide should answer

- How do you write down an agent's expected behavior?
- Which telemetry do you need to collect, and at which layer?
- How do you turn a divergence into an alert someone can review?
- How do you notice when monitoring itself has stopped working?

Response and enforcement (halting or quarantining an agent) are out of scope, as in the RFC.
